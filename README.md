
# Weather Assignment (Yellow.ai)

## Description
This project processes orders and updates them based on weather conditions using OpenWeather API.

## Features
- Uses Promise.all for parallel API calls
- Handles invalid city errors
- Updates order status

## How to run
npm install  
node index.js
